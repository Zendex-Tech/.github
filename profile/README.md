# Zendex

Zendex is a product engineering studio in Kochi, India, that designs, builds and ships web and mobile software for founders and established businesses.

- **Product engineering:** MVPs and new products, custom internal tools, rebuilds and migrations
- **Technical consulting:** system architecture, code and infrastructure audits, digital transformation roadmaps
- **Design and prototyping:** product and UX design, clickable prototypes, design systems

Every project is scoped to a fixed price, demoed as working software every week, and handed over in full: code, designs and documentation belong to the client.

It starts with a free 45-minute scoping call. Book one at [zendex.in](https://zendex.in/) or write to contact@zendex.in.
